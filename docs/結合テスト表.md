# 結合テスト表

画面をまたいだ一連の操作フローを、実際にアプリを操作して確認した記録。
単体テストのコードは無いため、このセッションで行った手動確認の証跡としてまとめる。

## 凡例

- **証跡の種類**: 「画面」= ブラウザ操作と表示内容の確認 / 「DB」= psqlでのテーブル内容確認
- 実施環境: `next-training-app`コンテナ上の開発サーバー(`http://localhost:3000`)、DBは同コンテナのPostgreSQL
